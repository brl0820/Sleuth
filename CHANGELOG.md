# Changelog

## 3.0.0
Primeira versão do repositório próprio do Sleuth.
- Atualização automática pelos Releases do GitHub: pacotes assinados (Ed25519), hash conferido, reversão automática e manual.
- Painel: categorias recolhíveis, espelhos e alternativas de download por fonte, teste de espelhos, seção Sobre e Atualizações.
- Fontes personalizadas só aceitam catálogos OPDS; cadastro valida com uma busca de verdade.
- Novo id do addon: `sleuth.search` (instalações antigas precisam reinstalar e reconfigurar).
