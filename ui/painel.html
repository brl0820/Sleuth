Escolha de onde o Sleuth procura, veja se cada site está respondendo e teste os links dos arquivos. Toque no título de uma categoria para abrir ou fechar.

Desligue as que você não quer usar. “Testar” faz uma busca de verdade na fonte e confere se o arquivo chega. Em “Espelhos”, abaixo de cada fonte, você vê, testa e acrescenta endereços alternativos do site para procurar o livro. Cada fonte com link direto tem também “Alternativas de download”: outros servidores para baixar o arquivo quando o link normal falha. O Mobilism não aceita espelhos, porque a sua senha iria junto.

    Alguns sites (como Anna’s Archive e Z-Library) só respondem a um navegador de verdade. O Sleuth usa um navegador próprio, escondido, e lembra as confirmações que você faz.

    O Sleuth se atualiza pelos Releases do GitHub. Só instala pacotes assinados pelo autor, confere o hash antes e volta sozinho à versão anterior se a nova não subir. Atualizações que mudam as permissões do addon nunca são instaladas sozinhas.

    Tudo o que o Sleuth faz, onde ficam os arquivos dele, o que ele já baixou e com quem ele conversa. Os tamanhos e os endereços acessados são medidos agora, no seu computador.
